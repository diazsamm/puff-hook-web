Petunjuk Perawatan & FAQ

Cara mencuci agar tidak melar?expand_more

Rendam dengan detergen cair lembut/sampo bayi di air dingin 10-15 menit. Keringkan mendatar (flat dry) beralaskan handuk bersih.

Lama proses pesanan custom?expand_more

Amigurumi & buket: 3-5 hari. Tas & cardigan: 5-7 hari kerja tergantung antrean studio.

Apakah aman dikirim ke luar pulau?expand_more

Sangat aman! Hard box karton tebal berpita & bubble wrap tebal 3 lapis menjaga bentuk agar tidak penyok.
